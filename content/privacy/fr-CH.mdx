# Politique de confidentialité

Le site [nopasaran.ch](https://nopasaran.ch) est édité par Rebel Suisse. Cette page décrit, de manière générale, les données qui peuvent être traitées lorsque vous utilisez le site.

## Consultation du site

Le site se consulte librement, sans compte ni inscription. Il est hébergé par des prestataires techniques qui peuvent enregistrer certaines données de connexion, comme l’adresse IP ou le type de navigateur, pour assurer son bon fonctionnement et sa sécurité.

## Statistiques

Nous utilisons un outil de mesure d’audience qui nous fournit des statistiques générales de fréquentation. Il ne dépose pas de cookies.

## Cookies

Le site n’utilise pas de cookies publicitaires. Un cookie technique peut servir à mémoriser la langue que vous avez choisie.

## Formulaire de contact

Si vous nous écrivez au moyen du formulaire de contact, les informations que vous transmettez (par exemple votre adresse e-mail, votre message et d’éventuelles pièces jointes) passent par un prestataire d’envoi de formulaires. Nous les utilisons uniquement pour traiter votre message.

## Réseaux sociaux

Nous publions les contenus du site sur nos comptes de réseaux sociaux, parfois de manière automatique. Ces publications n’impliquent aucune collecte de données sur les visiteurs du site. Les plateformes concernées appliquent leurs propres règles de confidentialité.
